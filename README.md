🤖 Smart Warehouse AMR Control & Digital Twin
📌 Project Overview

This project presents a Smart Warehouse Autonomous Mobile Robot (AMR) system with Digital Twin technology.

The system creates a virtual warehouse environment containing multiple AMRs, warehouse racks, pickup/delivery stations, charging areas, obstacles, and predefined navigation routes.

The main concept is to use AMR-01 as the physical robot while its virtual representation acts as a Digital Twin. Movement information is exchanged through MQTT, allowing the physical AMR to follow the route generated by the virtual system.

🎯 Objectives
Develop a web-based Digital Twin for a warehouse AMR.
Simulate warehouse routes and AMR movement.
Synchronize the physical AMR with its virtual representation.
Enable real-time MQTT communication.
Detect obstacles using physical sensor telemetry.
Support route rerouting when obstacles are detected.
Provide manual and autonomous robot control.
Monitor AMR status and sensor information.
Demonstrate multi-AMR task coordination.

📡 MQTT Communication

The dashboard communicates with the physical AMR using MQTT.

MQTT Broker
HiveMQ Public MQTT Broker

The web application uses a secure WebSocket MQTT connection:

wss://broker.hivemq.com:8884/mqtt

The default AMR topic is:

amr/demo/amr01

The dashboard subscribes to:

amr/demo/amr01/telemetry
amr/demo/amr01/status

and publishes robot commands through:

amr/demo/amr01/command
These MQTT settings are defined in the uploaded dashboard code.

🚨 Dynamic Obstacle Detection

The Digital Twin includes a dynamic obstacle system.

Obstacles can appear on warehouse roads during simulation. When an obstacle is detected, the system updates the Edge AI section and can trigger a route-analysis/rerouting response.

Example Edge AI command:

STOP / ANALYZE ROAD / REROUTE

The dashboard tracks the number of detected obstacles and displays their effect on the Digital Twin.

🚀 How to Run
1. Clone the Repository
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
2. Open the Dashboard

Open:

index.html

in a web browser.

3. Configure MQTT

The dashboard uses the HiveMQ WebSocket MQTT broker.

Default topic:

amr/demo/amr01

Make sure the ESP32 uses the corresponding MQTT topic.

4. Upload ESP32 Code

Open the ESP32 Arduino code in Arduino IDE.

Select the appropriate ESP32 board and COM port, then upload the firmware.

5. Connect the Robot

Power the physical AMR and ensure that the ESP32 has network connectivity.

6. Connect the Dashboard

Click:

CONNECT

in the Cloud / MQTT Connection section.

When the connection is successful, the dashboard displays:

CONNECTED

and activates the physical Digital Twin.

👩‍💻 Project Summary

This project demonstrates the integration of Digital Twin technology, MQTT communication, autonomous mobile robots, Edge AI, obstacle detection, route planning, and swarm intelligence for a smart warehouse environment.

The central concept is to create a virtual representation of the warehouse and AMR, use the virtual system for route planning and monitoring, and enable the physical AMR to imitate and synchronize with its Digital Twin in real time.
